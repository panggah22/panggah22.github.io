A Python implementation of the McCormick relaxation and multiparametric disaggregation technique for handling bilinear terms in optimization problems. This technique is particularly useful in power systems optimization where bilinearities arise from power flow equations.

**Features:**
- Piecewise McCormick envelopes for bilinear term relaxation
- Multiparametric disaggregation for improved accuracy
- Application to optimal power flow problems
