A Python wrapper that exposes the Kinect for Windows v2 API, enabling access to depth, color, body tracking, and audio data streams from the Kinect sensor in Python applications.

**Features:**
- Depth and color frame capture
- Body and skeleton tracking
- Audio beam processing
- Pythonic API design
